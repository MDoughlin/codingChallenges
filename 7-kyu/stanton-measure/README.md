<h2><a href=https://www.codewars.com/kata/59a1cdde9f922b83ee00003b/train/javascript target="_blank">Stanton measure</a></h2><h3>7 kyu</h3><p>The <strong>Stanton measure</strong> of an array is defined as follows:<br>Let <strong>n</strong> be the number of times the value <code>1</code> appears in the array.<br>The Stanton measure is then the number of times <strong>n</strong> appears in the array.</p><h3 id="task">Task</h3><p>Write a function that takes an integer array and returns its Stanton measure.</p><h3 id="examples">Examples</h3><ul><li><p>For <code>[1, 4, 3, 2, 1, 2, 3, 2]</code>:<br><code>1</code> appears <strong>2</strong> times → <code>2</code> appears <strong>3</strong> times → Stanton measure = <strong>3</strong>.</p></li><li><p>For <code>[1, 4, 1, 2, 11, 2, 3, 1]</code>:<br><code>1</code> appears <strong>3</strong> times → <code>3</code> appears <strong>1</strong> time → Stanton measure = <strong>1</strong>.</p></li></ul>
